# e-Tax Filing Designer

e-Tax の「XML構造設計書及び帳票フィールド仕様書」を元に、ブラウザの帳票へ直接入力し、PDF・XML出力を行う Web アプリのプロトタイプです。

対象は e-Tax 仕様書一覧の項番9〜13です。

- 9: 所得税
- 10: 法人税
- 11: 消費税
- 12: 資産税
- 13: 源泉所得税

## 起動

```sh
docker compose up --build
```

ブラウザで `http://localhost:8080` を開きます。

## 仕様ファイルの取得

公式 CAB を取得する補助スクリプトを用意しています。令和7年分所得税のXSD依存ファイルは、検証に必要な181ファイルだけを `schemas/r07` に収録しています。

```sh
sh scripts/download_specs.sh
```

CAB 展開後、公式の XML 構造設計書・帳票フィールド仕様書から `src/specs.js` と同じ形の JSON 定義を作れば、同じ画面生成エンジンで帳票を増やせます。

## 構造定義XMLから帳票を表示する

画面左側の「構造定義XMLを読み込む」から定義ファイルを選ぶと、セクション、入力項目、必須条件、入力形式を読み取り、直接入力できる確定申告帳票を生成します。

定義XMLの基本形は `examples/income-tax-definition.xml` を参照してください。

```xml
<filingDefinition title="帳票名" rootElement="TaxReturn" namespace="urn:example">
  <section id="basic" label="基本情報">
    <field id="name" label="氏名" path="Taxpayer/Name" type="text" required="true" />
  </section>
</filingDefinition>
```

対応する読込形式は次の3種類です。

- 上記形式の構造定義XML
- e-Taxで公開されているXSD（要素階層、`appinfo` の日本語名、型、`minOccurs` を反映）
- 入力済みXML（末端要素を入力項目として値も取り込む）

## 令和7年分 所得税申告書

起動時には、国税庁公開の令和7年分「所得税及び復興特別所得税の申告書」をHTML帳票として表示します。帳票フィールド仕様書 Ver23x の全788行（繰返し展開後894入力欄、719 XMLタグ）を収録しています。

- 申告書第一表・第二表
- 申告書第三表
- 申告書第四表（一）・（二）
- 申告書第四表付表（一）・（二）・（三）

- 帳票・XML構造定義: `examples/r07-income-tax-definition.xml`
- 帳票XMLスキーマ: `assets/forms/r07-income-tax/KOA020-023.xsd`（KOA020 Ver23.0）
- 手続ルートXMLスキーマ: `schemas/r07/shotoku/RKO0010-250.xsd`（RKO0010 Ver25.0.0）
- HTML/JavaScriptレンダラー: `src/html-renderer.js`

構造定義の各 `field` は、`path` に公式XMLタグ、`page` と `x` / `y` / `width` / `height` に帳票上の配置を持ちます。

帳票プレビューは画像を使用しません。毎回、生成したe-Tax XMLを再解析し、IT部の `ID` と帳票要素の `IDREF` を解決したうえで、sandbox化したiframe内のHTMLへ値を描画します。帳票内の水色の欄へ入力すると親画面の値とXMLへ即時同期されます。

帳票フィールド仕様書の値域277件、入力チェック278件、計算式70件、帳票間相関チェック12件を実行します。所得内訳4件、親族4件、特例条文3件などの繰返しは、XSD上の繰返し親要素として個別に出力します。日付・電話・郵便番号・還付口座は共通ボキャブラリの子要素と属性へ分解します。

準確定申告（申告種類3・4）の場合は、入力補足の指定に従って被相続人・相続人代表の情報を必須化し、`TEZ310 Ver9.0` を同じ手続XMLへ追加します。

## 完全準拠検証

次のコマンドで帳票フィールド仕様書・入力補足・別紙・公式XSDに対する網羅検証を再実行できます。

```sh
node scripts/verify_r07_compliance.mjs
node scripts/verify_r07_visual.mjs
```

検証内容は、全719タグ、繰返し47タグ、複合項目36タグ、277値域の328境界値、580形式ケース、70計算式、12相関条件、準確定申告とTEZ310です。結果は `reports/r07-compliance-report.json` に保存され、未検証項目が残る場合はコマンドが失敗します。

外観検証は国税庁「令和7年分 所得税及び復興特別所得税の申告書」第一表・第二表のA4比率、主要区画、色帯、桁枠、印刷寸法を基準にします。第一表141フィールド、第二表228フィールドが専用HTML上に重複・欠落なく配置されていることと、画像・SVGに依存していないことを `verify_r07_visual.mjs` で検証します。

画面の「HTML / CSS / JavaScript レイアウト」エディターでページごとのソースを直接変更できます。自動反映を有効にすると入力から約280ms後にプレビューが更新されます。`data-etax-field="フィールドID"` または `data-etax-path="XMLパス"` を付けた要素は入力欄としてXMLと連携し、JavaScriptからは `window.etax.value("XMLパス")` と `window.etax.update("フィールドID", 値)` を利用できます。編集コードは外部通信を禁止したsandbox内で実行します。

### 帳票デザイナー

「HTML / CSS / JavaScript レイアウト」内の帳票デザイナーでは、A4キャンバス上へ文字、入力部品、罫線、枠を配置できます。部品はドラッグ移動、右下ハンドルでのサイズ変更、mm単位の座標・寸法指定、複製・削除に対応します。

左側のXSD構造ツリーから項目を検索して入力部品へ割り当てると、フィールドIDとXMLパスが設定されます。「実行画面へ反映」でHTML/JavaScriptへコンパイルされ、帳票入力と正式e-Tax XMLが双方向同期します。

入力部品には、ほかのフィールドIDを使った四則演算、必須、最小値、最大値、正規表現、任意のエラーメッセージを設定できます。計算結果も通常の入力と同じ経路でXMLへ反映されます。生成されたHTML/JavaScriptは従来のソースエディターでも確認・編集できます。

正式e-Tax XMLは画面とXML生成の唯一の正本です。帳票は表示中XMLをフルパス、繰返し順、複合項目、`IDREF`で解析して描画します。XML欄を直接編集して「XMLを帳票へ反映」を押すと帳票を再描画でき、帳票上の入力は同じXML要素へ反映されます。入力済みのRKO0010/KOA020 XMLファイルを読み込んだ場合も、この経路で帳票化します。

画面右上の「PDF保存」は表示中の帳票をA4印刷レイアウトで開きます。ブラウザの印刷画面で「PDFとして保存」を選択してください。入力欄の背景色や画面用の補足表示はPDFには出力されません。

出力XMLは帳票単体ではなく、正式な手続構造で生成します。

- `DATA / RKO0010 / CATALOG / CONTENTS` の外枠
- 共通納税者情報を格納する `IT` 部
- `id`、`ID`、`IDREF` による共通情報参照
- 手続・帳票・ITの各バージョン
- `softNM`、`sakuseiNM`、`sakuseiDay` の作成情報
- XSDの `sequence` に沿った複合項目と帳票階層

画面右上の「XSD検証」は、生成したXMLの手続コードに対応する公式ルートXSDと全依存XSDへサーバー側で照合し、結果とエラー箇所を画面に表示します。この機能を使う場合は `docker compose up --build` で起動してください。

### 予定納税額の減額申請（PKO0420 / KOZ280）

所得税関係の申請手続にも対応しています。サイドバーの「予定納税額の減額申請書を表示」から、公式仕様の次の組合せを開けます。

- 手続ルート: `PKO0420 26.0.0`（`shotoku/PKO0420-260.xsd`）
- 対象帳票: `KOZ280 21.0`
- 帳票名称: 年分所得税及び復興特別所得税の予定納税額の7月(11月)減額申請書
- XML構造設計書: `XML構造設計書(所得-申請)Ver21x.xlsx` の114行
- 画面フィールド: 繰返し4件を展開した117フィールド

検証サーバーはXML内の手続コードを読み取り、`RKO0010` には `RKO0010-250.xsd`、`PKO0420` には `PKO0420-260.xsd` を自動選択します。入力済みの正式e-Tax XMLを読み込む場合は、ルートXSDへの適合を確認した後だけ `KOA020` または `KOZ280` の対応帳票を生成します。

`PKO0420 / KOZ280` は予定納税額の減額「申請」であり、確定申告書の `RKO0010 / KOA020` とは別手続・別帳票です。

## 現状の実装範囲

- 税目別の帳票選択
- 帳票上の直接入力とXML同期
- 必須・形式チェック
- 帳票フィールド仕様書の値域・端数処理・条件付き必須チェック
- 仕様書記載の70計算式と12帳票間相関チェック
- KOA020-1〜KOA020-8の全帳票と繰返し項目
- 国税庁公式XSDによる出力XML検証（令和7年分所得税）
- 罫線付き帳票プレビュー
- XML プレビューと XML ダウンロード
- 表示中帳票のA4 PDF保存
- 構造定義XML・e-Tax XSD・入力済みXML・JSON定義の取込
- Docker/nginx によるブラウザ実行環境

令和7年分所得税以外の税目は引き続きプロトタイプ定義です。電子署名の付与とe-Taxへの送信機能は含みません。
